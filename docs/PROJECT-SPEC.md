# 项目定位、产品目标和功能范围

## 定位

观势（Stock Radar）是个人单用户的A股热点启动与突破提醒工作台。目标市场为沪深主板、创业板和科创板：通过市场环境、板块共振、个股突破与风险过滤形成可解释候选，由用户自行判断并手动交易。

“值得关注”表示在固定规则与当时可见信息下满足条件的候选，不代表全市场最优、上涨概率或确定盈利。软件不自动下单。

## 目标流程

用户于 2026-11-14 进一步要求持续事件采集、最新行情与估值过滤、自动策略信号和买入提醒。新目标及配置建议见[持续采集与提醒方案](requirements/06-持续事件采集与买入提醒方案.md)，当前尚未启用常驻采集或真实提醒，沿用既有策略与发布证据要求。

盘前确定参考区间和有效股票池；交易时段只使用完成的分钟切片，计算市场/热点，再筛选个股。通过数据、量能、风险、参与范围与分数门槛后生成预警；随后确认、暂停、失效或过期。用户可记录观察/忽略/已买入反馈，系统保留证据和后续研究。

判断依据不依赖LLM在线，实时与历史回放共用同一策略路径。参数、数据、代码版本及失败样本可追溯。

## 发布与证据边界

四种模式为fixture、replay、shadow、live_alert。当前应用明确拒绝live_alert；保存新版本或修改mode不能绕过发布门槛。

真实提醒前需真实行情/钉钉路径实测，冻结参数与样本外比较，全市场覆盖/负载/P95时延、建议不少于20交易日影子观察及断源/重启/备份恢复证据。缺少成熟5/10/20日目标收盘时为pending，未配置/验证成本时净收益为null，不能把合成结果包装成投资效果。
