# 网站页面和详情结构

当前产品为本地研究工作台，页面用Hash路由，不需要服务端单独的HTML页面。静态入口为`/`，API前缀为`/api/v1/`。本项目没有组件商城、营销官网或`/components/{slug}`详情页；本文件的“详情”对应信号、热点和通知侧栏。

## 路由与公共外壳

| 入口 | 含义 | 渲染/控制入口 |
|---|---|---|
| `/`未登录 | 令牌登录页，静态装饰与模拟说明 | index.html、connect |
| `#market` | 市场与热点 | renderMarket |
| `#signals` | 机会信号 | renderSignals |
| `#signals/{id}` | 信号列表并打开指定详情 | route、openSignal |
| `#research` | 策略与研究（含 `#research/strategy-preferences` 常用策略配置） | renderResearch、setup-view.js |
| `#settings` | 设置与诊断 | renderSettings |
| `#setup` | 首次设置引导；主导航归属设置 | renderSetup、setup-view.js |
| `#market-api` | 独立行情API配置；主导航归属设置 | renderConnections、connection-view.js |
| `#minute-data` | 真实行情：Fuyao报价/日线及Tushare分钟；主导航归属设置 | renderMinutes、real-market-view.js、minute-view.js |
| `#models` | 独立大模型连接配置；主导航归属设置 | renderConnections、connection-view.js |

未知Hash回退市场页。详情深链中的ID是业务标识，不带凭据，访问后仍需登录。

登录后公共外壳包含：桌面左侧导航/移动底部导航、顶栏面包屑、连接状态、刷新、通知入口、主体内容和风险语义页脚。每页显示运行模式；fixture/replay说明模拟或研究边界，质量异常时显示原因。认证失败返回登录，不继续展示为已连接。

本轮界面优化固定顶部栏、统一字号与焦点样式，模式条增加完整北京时间行情时点，手机标题和操作分行。刷新错误展示缓存说明和重试入口；搜索草稿与已应用条件分别保存。初轮仅完成代码与自动测试，当时未执行浏览器检查，见[专项记录](development/ui-polish.md)。

侧栏股票范围来自health.boards：新配置可显示沪深主板/创业板/科创板，旧运行版本保持原范围，未知时显示未知。NEXT08核对新旧桌面显示与390px科创详情，并避免窄侧栏将板块名称拆字；没有新增真实提醒启用操作。

## 市场与热点

自上而下为标题与模拟推进/重置、中性模式条、读取错误与需要核对的事项、紧凑市场/热点/机会/覆盖概览、当前机会表格、热点列表与市场依据。异常项展示对象/时点、原因及现有处理入口，按数据与投递依赖优先，信号项仅来自当前列表。

数据来自health、market、sectors、signals。热点展示状态、RS及改善、广度、同期量能和覆盖；查看热点详情展开计算依据与成分。统计必须注明合成股票池分母，UNKNOWN不包装为下跌或退潮。

## 机会信号

包含模式提示、待核对事项、状态筛选、代码/名称搜索、稳定排序列表、分页/游标和空/错误状态。列表区分信号与参与状态，价格/分数右对齐，原因与下一步同列可比较；股票单元格保留关联热点。参与状态未知时不补成暂停。

信号表保留原生表格语义，股票名称按钮提供键盘详情入口；首列在横向滚动时固定，窄屏提供横移说明。滚动容器可聚焦，重绘保留横向位置及股票按钮焦点；鼠标仍可点击整行。筛选通过aria-pressed标明当前条件。

数据来自signals及详情API。分页过程中数据变化会令游标失效，返回CURSOR_STALE后从第一页重新获取。内部DETECTED记录可查询，但不是已发预警。

## 策略与研究

包含版本列表、完整参数JSON编辑、新版本保存、回放版本选择、样例回放提交及任务记录。功能回放结果包含对照、信号/事件数、覆盖、数据/配置/代码/结果哈希和局限。

「研究策略卡」位于页面上方。读取后按固定配置展开各次研究，保留基准、成熟样本分母、待定和跨段剔除。卡片可打开相同窗口的完整比较或案例侧栏。 [卡片与案例口径](development/history-workbench.md#研究策略卡)

新增独立成本研究区域：选择数据集与完整计划，异步运行study；切换研究/验证/测试段、反应延迟、持有窗口与退出假设，比较四组有效分母、闭合/待定/未成交、净收益、超额及聚类区间。可导出含原样本的完整报告，合成演练和真实自备数据按原标记区分。

数据来自strategy-versions、replays、study-sources、studies和diagnostics。内置study为30日合成样例；自备文件预先放到独立数据库旁的datasets与study-plans，页面无上传或任意URL读取入口。编辑参数不自动切换运行策略，保存版本不等于发布。未成熟窗口为pending，未知收益为null，页面显示“—”。完整计划和输入在提交时冻结，研究不写实时信号/持仓/通知。

## 设置与诊断

包含数据提供方与能力声明、模式/时间/覆盖、内置通知与钉钉状态、显式测试按钮、配置导出、真实提醒发布条件、候选过滤原因和运行日志。钉钉当前配置的连接受理与真实机会路径分开展示，历史其他配置的成功不能算当前验证。

数据来自health、notifications、diagnostics、config/export。顶部子导航通向独立行情/模型配置页。钉钉仍由服务端环境配置；点击测试才调用钉钉测试API，当前没有真实提醒启用按钮。

## 行情API与大模型配置

两页均由connections读取不含Key原文的状态，POST分别保存或显式测试。行情页按服务商列表选择Fuyao/TickFlow/Tushare，展示固定地址、Key来源、个人研究权限依据；模型页填写兼容API基础地址、模型ID、超时和Key。本机兼容服务可不填Key，远程使用HTTPS。独立表单沿用现有panel/button/tag/token。

保存/替换/清除Key均写入数据库旁的独立本地令牌文件，不进入策略配置或数据库。留空保留，清除须勾选后保存；环境变量优先时明确提示。后台刷新保留正在编辑的表单，普通字段草稿与Key分开；Key不进入浏览器存储，提交即清空，失败提示重新输入。旧修订覆盖拒绝，可恢复已保存内容。

行情测试须Key与访问依据完整；模型只读取模型目录，不发送生成请求。配置状态、接口可达、推理能力和策略发布状态分别表达。完整边界与本轮验收见[连接配置](development/connection-settings.md)。

行情 API 配置下方的「数据源健康」可按需读取本机采样记录。展开供应商接口行查看请求次数、最近完整响应、限流、诊断覆盖及近期报告标识。读取记录时保留配置草稿。 [采样目录与显示口径](development/history-workbench.md#数据源健康)

## 真实行情

顶部Fuyao面板显示报价和可展开日线、服务商批次/逐股未知时间、本机接收年龄及错误，显式两请求手动刷新；下方保留Tushare分钟表单。[实际验证](development/real-market-view.md)。

独立“分钟行情”页先管理Tushare所选接口、1—3只证券、显式历史日期和本次访问确认，再做零请求检查或手动获取。最新/当日/历史权限分开表达；轮询只读本机记录，表单草稿不随刷新丢失。原始图表/数值显示来源标签和接收时间，未知不补0，不复用信号详情的“完成分钟”语义。分钟记录与顶部策略运行模式分别说明，见[使用与验证](development/tushare-minute-feed.md)。

## 信号详情侧栏

`signalDetail`按如下顺序组织：

1. 股票、代码、主热点、策略版本、规则分、信号/参与状态。
2. 当前核对事项和保存的首个原因，提供查看完整依据/记录处理的定位入口。
3. 冻结触发价格/时间、最新价格/时间、H/ATR/S、参与范围与到期时间。
4. 全部触发/限制原因、关联、来源/快照/标签。
5. 分钟K线：默认触发时可见，后续行情单独展开；冻结H/S、事件、累计成交额和来源/修订/可见时间表，排除缺失与复权基准变化。
6. 分项评分、权重与原始特征。
7. 观察、忽略、已买入反馈及最近操作；明确不生成成交。
8. 追加信号事件时间线与通知投递/尝试记录。

详情由signals/{id}提供，展示最新状态并保留原事件证据。桌面侧栏约600px，移动端全宽；关闭行为与焦点要求见[组件规范](COMPONENT-GUIDELINES.md)。

## 热点与通知详情

热点侧栏由 `openSector` 展示当前板块的相对强度、广度、量能、覆盖、门槛依据与成分表。打开时读取已保存的热点阶段时间线，可跳到历史切片并核对暂停、恢复、指标和代表成分。 [时间线范围](development/history-workbench.md#热点阶段时间线)

通知中心由`openNotifications`展示渠道、存储/投递状态、事件摘要、尝试次数和响应，可跳转关联信号。inbox accepted表示本地保存，不写“平台已送达”。
