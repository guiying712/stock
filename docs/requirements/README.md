## 给开发 AI 的执行规则

- 本目录最初用于需求定义；用户现已授权产品开发，选择钉钉，并先完成离线版本和数据接入接口。真实行情供应商待定。
- 继续开发以本目录为当前产品基线，并结合开发文档和代码核实实现状态。用户后续明确指令优先于本文。
- `U` 表示用户已明确表达；`D` 表示为可开发性提出的暂定设计；`E` 表示待验证实验参数。不要将 D/E 写成用户承诺或已验证事实。
- 从数据契约、离线样例和确定性策略开始；不等待全部待定项，不虚构外部服务可用性。涉及真实数据选型、费用和通知接入时再解决对应依赖。
- 不得因旧蓝图而新增自动下单、券商连接、多市场或通用聊天主界面。
- 所有必需参数缺失时，返回配置错误；演示模式与真实行情模式明确隔离。不得偷偷用演示值开启真实机会推送。
- 实时监测与历史回放共用指标和策略实现。LLM 不得成为算分、风险过滤和通知触发的必经环节。
- 每项交付应标记需求 ID、验证证据、已知限制及未完成项；工程验收通过不等于投资效果有效。

## 已确认决策与待完成依赖

| 决策 | 当前做法 | 最迟决定时间 |
|---|---|---|
| 行情服务商、授权与预算 | 定义可替换接口，使用明确标记的测试数据 | 真实数据 PoC 前 |
| 常驻运行位置 | 本地开发，后台服务与页面分离；可迁移常驻主机 | 连续盘中运行前 |
| 通知渠道 | 已确认钉钉群机器人，内置收件箱已实现；真实群尚未配置 | 真实渠道PoC前完成目标群配置 |
| 钉钉接入方式 | 官方Webhook与可选HMAC加签代码已实现；只开放显式测试，不开放卡片回调 | 服务端签名、平台受理与超时行为仍须实测 |
| 正式策略参数与分数门槛 | 离线实验，冻结版本后进入影子运行 | 真实机会推送前 |
| 提醒数量偏好、持仓反馈使用意愿 | 可配置；轻量反馈作为 D 类设计 | 试用前 |

四页界面、确定性策略、事务持久化、离线回放、适配器及本地模拟聚合/调度已具备；全市场真实数据、真实群跨股票消息呈现/受理、完整历史评价与连续影子运行仍未验收。开发任务和已知问题统一在[进度文档](../../TODO.md)维护，避免将旧研究蓝图当成当前待办。

“影子运行”指真实行情计算、保存结果，但不向用户的外部渠道发送投资机会；运行故障通知另行配置。
