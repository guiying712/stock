# 观势 · 用户配置与选择

以 0.2.7 的实现和首版需求为依据。「建议」表示待产品确认的交互或字段。 [产品范围](../PROJECT-SPEC.md) · [当前进度](../../TODO.md)

## 首次设置与日常操作

| 项目 | 用户配置或选择 | 0.2.7 现状与建议 |
|---|---|---|
| 行情连接 | 选择 Fuyao、TickFlow 或 Tushare 的连接档案，填写或更换 Key／Token，确认访问用途及依据，显式测试 | **已有页面**「设置与诊断 → 行情 API」。配置档案供连接测试和采样使用。正式运行的数据源选择应按数据集显示已验收能力，保存连接与启用采集是两个操作 |
| 分钟研究采样 | 选最新、当日或历史分钟，填 1–3 只证券。历史模式选日期范围，确认本次访问后手动获取 | **已有页面**「分钟行情」。零请求检查与获取分别操作。四阶段验收计划另通过 JSON 设置标的、交易日、采集时点和总预算 |
| 钉钉通知目标 | 填写目标群机器人的 Webhook，按机器人配置提供加签密钥，显式发送测试 | **已有环境变量与页面测试入口**。建议集中展示当前连接状态、最近测试结果和更换配置后的待复测状态。首版外部渠道已确定为钉钉，内置中心随应用提供 |
| 机会查看与反馈 | 按状态、代码或名称筛选信号。对单条机会选择观察、忽略或已买入 | **已有页面**。这些是查看条件和逐条反馈。「已买入」保存用户自报的状态，实际成交价格和数量属于后续持仓功能 |
| 模型连接 | 填写兼容 API 地址、模型 ID、超时和 Key，显式检查目录 | **已有页面**「大模型」。首版只检查模型目录。将来若实现 AI 解释，再提供单独开关和解释偏好 |

## 策略与研究

下面的选项会影响信号结果或研究口径。页面可给常用字段提供表单，底层继续使用完整、可校验的策略版本和研究计划。

| 项目 | 用户配置或选择 | 0.2.7 现状与建议 |
|---|---|---|
| 扫描范围 | 查看默认全范围「沪深主板＋创业板＋科创板」，实验时选择其中的板块子集 | **已有策略 JSON** `preferences.boards`。建议在选版本时显示实际范围及覆盖率分母。自选或采样标的属于局部任务 |
| 提醒时机 | 选择启动预警或确认后提醒 | **已有策略字段** `research.alert_stage`，目前通过 JSON 和研究计划管理。建议在策略版本表单用两项选择，说明前者更早、后者要求满足确认条件。真实推送仍须通过发布验收 |
| 结构风险上限 | 可选择更严格的单笔结构风险上限 | **已有策略 JSON** `preferences.max_loss_fraction`，允许大于 0 且不超过 10%。它用于信号筛选时参考价到结构失效位的距离。正式运行值由研究验证后冻结 |
| 新机会数量与合并 | 每日新增机会额度、同热点通知聚合窗口 | **已有策略 JSON** `lifecycle.daily_new_limit` 和 `runtime.group_window_seconds`。建议表单解释「每日额度为 0 表示不限」「合并窗口为 0 秒表示关闭聚合」，并保留已发信号的风险更新 |
| 策略高级参数 | 市场基准与窗口、热点强度和广度门槛、个股突破与 ATR、最低成交量额、评分权重和门槛、确认与过期规则 | **已有 JSON 编辑和创建版本**。建议在高级区域管理。缺项和未知字段报错，修改时新建版本并保留配置哈希。正式阈值和退出方式尚待验证 |
| 运行版本 | 查看当前版本，选择已保存版本用于回放。运行进程由部署时显式选择版本 | **已有页面回放选择、CLI 启动配置**。保存新版本不会切换运行版本。建议将「保存草稿」「用于回放」「显式选择运行版本」在操作上分开 |
| 研究任务 | 选数据集和完整计划，设置历史分段、反应延迟、持有窗口、退出假设、成本和基准 | **已有页面选择数据集和计划**，高级参数在研究计划 JSON 中。结果页已有分段、延迟、持有窗口和退出假设筛选。切换已有报告的查看条件只改变展示 |

## 部署配置与系统约束

2026-11-14 新增事件源、采集时段/频率、预算、补采、OCR/模型、行情估值及提醒配置建议，见[持续事件采集与买入提醒方案](06-持续事件采集与买入提醒方案.md)。这是新目标配置，当前页面尚未实现，不把建议值作为已启用的生产参数。

| 项目 | 归属 |
|---|---|
| 本机端口、数据库位置、访问令牌、标准行情网关、采集进程与运行版本 | 由安装者或维护者通过 CLI、环境变量或受保护的本地文件设置。Key、Token 和 Webhook 与策略导出分开保存 |
| 交易日历、交易阶段、历史证券状态、复权、量额单位、数据可见时间 | 由有依据的数据契约和版本化规则维护。页面显示来源、缺口和通过状态。研究者可在独立验收计划中提交依据 |
| 切片频率、覆盖与新鲜度、去重、投递结果未知 | 当前策略使用完成的 60 秒切片。覆盖、新鲜度和采集超时属于高级运行配置，经验证后随版本冻结。去重、风险更新优先和未知投递处理由系统执行 |
| 模式及真实发布 | 演示、回放与影子有各自的数据和运行条件。`live_alert` 当前由应用锁定，发布前须验收真实行情、外部渠道、样本外研究及连续影子运行 |

建议先把**行情连接、钉钉测试、当前策略版本与扫描范围**做成一条清晰的设置路径。第二批再给**提醒时机、每日新机会额度和结构风险上限**提供表单，提交后生成新版本。配置入口和操作细节见现有说明。 [连接配置](../development/connection-settings.md) · [分钟行情](../development/tushare-minute-feed.md) · [研究与回放](../development/four-priorities.md) · [部署](../DEPLOYMENT.md)
