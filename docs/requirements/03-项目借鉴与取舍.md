## 2. 当前优先级与实际吸收结果

先验证 tick-stock-panel 的统一策略/数据契约、a-stock-data 的必要数据能力、daily_stock_analysis 的通知与回退路径；Vibe-Research 主要用于产品流程参考。TradingAgents 从旧资料中的编排 P0 下调为审计设计参考。

| 吸收的设计 | 落到本产品 | 验收依据 |
|---|---|---|
| 数据能力与业务模块解耦 | ProviderCapabilities、来源/质量字段 | FR02、AT05/11 |
| 实时和回放同一计算路径 | Strategy.evaluate、冻结快照 | FR12、AT01/16 |
| 突破与量价证据可解释 | H/ATR/S、标签与原因码 | FR05/06、AT02/03 |
| 通知与研究产物衔接 | 信号详情、状态更新、投递日志 | FR08/09、AT07/08 |
| 研究过程可复现 | 配置版本、时间切分、对照实验 | FR12/14、AT14/16 |
| AI 与确定性计算分离 | 可选解释、模板兜底 | FR16、AT12 |

这里的事务发件箱、10% 距离门槛、热点状态机等是本产品的具体设计，不声称由某一个上游项目原样提供。

## 4. 复用决策的交付格式
