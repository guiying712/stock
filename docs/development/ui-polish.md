# NEXT11 · Impeccable界面优化

本次在观势0.2.0源码上使用Impeccable 4.8.0的polish/Operate流程打磨现有工作台。保留浅灰底、白色面板、深绿主色和现有四页结构。没有新增运行依赖或修改策略、配置、API契约、实际数据库、令牌及research来源快照。

## 改动与使用

- 模式条同时显示运行模式、完整北京时间行情时点及真实提醒状态，便于区分模拟时间和服务连接。
- 正文/辅助说明统一为12—14px，手机输入16px；桌面按钮通常40px，手机主要按钮和图标44px。次要文本、状态标签、输入边框和焦点使用统一token。
- 信号表的股票首列固定，名称按钮可用键盘打开详情；鼠标仍可点整行。窄屏可聚焦滚动区域并横向查看其余字段。热点在中等宽度收起量能列，手机再隐藏排名，完整数值仍在详情。
- 未提交搜索文字与已应用查询分别保存，刷新保留草稿、股票按钮焦点和信号表滚动位置。详情打开时背景inert，关闭可按稳定ID返回更新后的入口。
- 健康请求失败仍渲染旧数据说明和重试按钮。演示推进/重置、登录显示进行中文字样，操作具有aria-busy；错误Toast使用alert。质量提醒保留文字，不依赖颜色。

原生JS、Hash路由、静态白名单和包内五份静态资源保持同一入口。启动仍按[README](../../README.md)操作；当前没有新开关或真实提醒启用入口。
