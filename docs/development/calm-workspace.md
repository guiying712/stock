# NEXT11补充 · 安静有序的任务工作台

本轮使用calm-workspace-design调整0.2.2现有界面。沿用浅色/深绿身份、原生ES modules和共享组件，围绕“异常对象 → 当前依据 → 下一步”组织信息。只修改前端展示与交互，未修改策略、参数、API契约、实际数据库、凭据或research来源快照，未新增运行依赖。

## 当前阅读与操作顺序

概览从运行模式与行情时点开始。有需要核对的事项时，先展示数据依赖、外部投递结果，再展示当前已加载活跃信号的暂停/偏离；最多显示3项，同时说明剩余项和列表范围。这里的顺序用于核对，不是投资排序。没有这些事实时不制造“异常”，合成模式本身保持明确标注。

四个概览卡片压缩为同一比较条，机会列表提前到热点与市场依据之前。列表将股票/热点、信号与参与状态、最新/触发价、规则分、触发时点、已保存原因和下一步对齐。数量说明样本范围，未知状态和价格保持未知，不以0或暂停填补。

详情顶部先给出核对事项和已保存原因，并提供“查看完整依据”“记录我的处理”的定位入口；两个入口只移动滚动与焦点。价格、冻结H/ATR/S、期限、来源、K线、评分和历史记录继续可查。反馈仍需用户明确点击，只记录反馈，不产生实际成交或持仓。

初始请求完成前显示加载面，防止市场尚未读取而信号已返回时混显0计数。后续失败显示缓存说明和重试；搜索草稿、表格横向位置、详情跳转标题和返回焦点继续保留。外部unknown不与模拟队列混计，也没有添加自动重发入口。

## 迭代事实与限制

最初动态import遇到本地CommonJS包装不兼容，改用已有包的标准require；Playwright自带浏览器未安装，使用已安装Chrome。受限环境下Chrome启动失败后，经执行授权在同一临时服务上完成隔离测试，未修改Work设置或使用原有浏览器资料。

第一次前端检查有2处断言依赖旧类名/标题，更新为新结构；新增XSS测试的测试字符串转义错误改为JSON构造。首轮渲染捕获了初始请求混显，新增加载状态和回归后修复。两次浏览器运行分别在原生滚动尚未完成、hashchange尚未渲染时过早断言；改为等待对应完成条件后，上述最终路径通过。窄屏截图等待稳定绘制，暂停图另在新上下文补拍以免短暂Toast遮挡。记录见[迭代说明](evidence/calm-workspace-20261031/iterations.json)，先前浏览器结果另存，没有记作最终通过。

本轮不证明真机、软键盘/安全区、读屏、200%浏览器缩放、其他浏览器或完整WCAG达标；这些项目仍在TODO。未重建或发布wheel，源码版本保持0.2.2，已有wheel不包含本轮改动。真实数据接入、真实提醒、全市场与投资效果的门槛保持原约束，live_alert继续锁定。

临时工作与演示库位于`/private/tmp/stockradar-calm-workspace-xxw1mvq0`；持久证据不包含令牌或浏览器资料目录。收尾只核对源码/文档与证据，不把上述测试重记为新执行。
