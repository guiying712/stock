# 真实行情查看与手动刷新

2026-11-13 UTC在0.2.7源码上新增独立Fuyao报价/日线查看。已使用现有本地连接实际请求并通过浏览器刷新；来源为服务商真实响应，逐股行情时间没有提供，不能据接收时间保证盘中实时性。版本仍为0.2.7，本轮未打包或发布wheel。

## 使用

启动 `python3 -m stockradar serve --port 8765`，用该服务的本机访问令牌登录。进入「设置与诊断 → 真实行情」（`#minute-data`）。行情API中的Fuyao Key和访问依据须已保存；页面不回显Key。

页面显示本机已保存记录，展开股票行下方的日线明细可看日期和OHLC。点击「获取真实行情」前勾选本次研究确认；固定请求600000.SH、300750.SZ、688981.SH的报价及截至北京时间昨天、最近7个自然日的未复权日线。每次2个批量请求、间隔6.1秒，两轮至少60秒，不自动重试。当前日即使已收盘也不取，休市日不自行补行；本次返回2026-11-06、09、10、11、12各一天，共15条。

「读取本机记录」、顶部刷新和12秒页面轮询只读本地，不调用服务商。请求失败显示错误；已有结果保留；服务商返回不完整报告则展示本轮不完整内容。接收超过5分钟显示旧记录；这只是本地缓存年龄，不是行情时效承诺。批次时间与逐股行情时间分列，后者保持未知；批次晚于接收会提示。

## 存储、接口和范围

`real_market.py`复用采样器、严格计划和独占锁，原始响应、哈希、计划及报告保存在数据库旁`real-market/<随机ID>/`。读取验证清单与样本哈希。GET `/api/v1/real-market`只读；POST `/api/v1/real-market/fetch`需现有Bearer鉴权及来源检查，正文为 `{"schema_version":1,"mode":"latest","symbols":["600000.SH","300750.SZ","688981.SH"],"access_confirmed":true}`。后端允许1至3只合法代码，前端本轮固定上述3只。

本次临时查看服务使用 `/private/tmp/stockradar-real-market-session/radar.sqlite3` 隔离数据库，连接引用项目既有 `data/.connections`，新行情保存于项目 `data/real-market`。原策略数据库未改动；服务关闭或电脑重启后须重新启动。普通CLI以所选数据库的相邻目录查找连接和行情。

对应NEXT03的数据来源实采与查看、NEXT11的来源/时间/异常展示；不代表FR全市场扫描验收。策略仍使用原模式，Tushare分钟权限待配置，数据尚未进入标准batch/evaluate，live_alert继续锁定。成交量单位、历史资格、分钟完整性与持续盘中时效仍需独立验收。
