# 数据源健康、热点时间线和研究策略卡

观势 0.2.6 从本机已保存的采样、扫描和成本研究中展示这三类记录。真实分钟账户权限、标准行情批次及真实提醒继续按项目发布条件验收。 [发布条件](../PROJECT-SPEC.md#发布与证据边界)

## 数据源健康

进入「设置与诊断 → 行情 API → 数据源健康」，点击「读取本机记录」。展开接口行可查最近完整响应、完整/部分/空响应/失败次数、限流次数和最近五次请求。记录按供应商、数据集、接口和原模拟标记归类。完整响应沿用采样报告中的 `captured`，按实际发出的请求计算分母。

页面按采样报告的文件修改时间，在下列两个采样目录各读取最近 24 份报告。相同报告哈希只计一次，零请求准备记录不计入请求次数。接口行中的时间按北京时间展示。

| 数据库所在目录下的位置 | 可放置的记录 |
|---|---|
| `minute-data/<采样目录>/report.json` | 「分钟行情」手动获取时生成 |
| `source-samples/<采样目录>/report.json` | 已完成的 `vendor-sample` 目录。可指定该位置为输出目录，也可复制已有目录 |
| `source-quality/<报告名>.json` | `minute-quality --output` 生成的分钟诊断报告。页面检查最近八份，并匹配采样报告哈希 |

采样清单核对计划、请求及文件哈希引用。需要重验原始响应时，用对应采样与分钟诊断工具检查完整目录。可用以下命令在临时工作台查看已归档的 Fuyao 采样记录。

```sh
review_dir="$(mktemp -d)"
mkdir -p "$review_dir/source-samples"
cp -R docs/development/evidence/fuyao-poc-20261108 "$review_dir/source-samples/fuyao"
python3 -m stockradar serve --db "$review_dir/radar.sqlite3"
```

「诊断样本有效分钟」显示匹配诊断中可用去重分钟数及预期分钟数。缺少明确日历、分钟标签或匹配诊断时，覆盖率保持待核验。最新分钟延迟只采用同一北京时间交易日内、已完成区间的首次观测，展示样本数、最大观测间隔及超出计划预算的次数。历史及当日分钟下载的接收时间仅用于核对采样记录。 [诊断口径](next03-minute-quality.md)

## 热点阶段时间线

进入「市场与热点 → 热点雷达」，选择板块后点「查看热点阶段时间线」。侧栏先展示当前板块，再按时间呈现当前运行策略版本最近 48 个已保存扫描切片中的首条、变化点和末条。

变化点保留板块阶段、数据暂停与恢复、门槛、理由、来源、快照 ID、相对强度、广度、同期量能和有效成分分母。代表股是当时有效成分中已知涨幅最高的三只。板块曾出现后在某切片缺席时，时间线显示缺少板块。当前运行健康状态仍可从侧栏的质量依据核对。

## 研究策略卡

进入「策略与研究 → 研究策略卡」，点击「读取策略卡」。若尚无已保存的研究，可先在同页「成本与样本外研究」运行内置合成演练。卡片使用最近 30 个任务中的已完成报告，预览最多八份不同的报告，累计读取上限 128 MiB。

卡片按固定配置哈希、对照组和原模拟标记分组。每次研究保留独立的样本分母、闭合/待定/未成交、跨段剔除、净收益、相对基准及失效计数。展开可查评分权重、冻结条件、样本缺口和计划、数据、代码、报告哈希。

卡片默认读样本外测试段、固定退出、反应 1 分钟和持有 5 个交易日。计划缺少相应反应延迟或持有期时，各取该计划最短的可用值。「打开研究比较」会选中卡片所示口径，完整报告可继续查看其他分段、退出和持有设置。

「查看案例」在同一口径下列出至多六条结构失效或负净收益案例，按净收益从低到高排序，并列出至多四条待定或未成交案例。新报告可核对触发时间、首次提醒、代码、触发快照及模拟出入场。早期报告可用已有的信号 ID 回查，缺少的字段保持未知。
