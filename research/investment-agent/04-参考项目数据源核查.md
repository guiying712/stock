# 24 个参考项目的数据源核查

核查日期：2026-11-11（America/Los_Angeles）。范围为 [project-registry.json](project-registry.json) 登记的全部 24 项，包括新增的 dsh-market-lens 和 marketingdashboard。沿用各项目已经归档的固定提交，在线读取关键取数代码及上游文档；不将固定版本描述为最新 main。

**结论：A 股项目大量共用东方财富、腾讯、新浪、BaoStock、通达信；账户型服务主要有 Tushare、TickFlow、Fuyao、TdxQuant 以及券商/专业数据商。美股项目常用 Yahoo、Finnhub、Alpha Vantage、Financial Datasets，财报常来自 SEC。项目数量远大于独立数据来源数量。**

本次为静态来源研究：没有运行上游项目、请求证券行情、读取凭据、接入观势策略或修改真实提醒门槛。代码中的默认顺序可被配置、市场类型与健康状态改变；“有接口代码”不等于权限、覆盖、持续可用性或数据质量已通过实测。

## 怎么理解来源

| 层级 | 例子 | 本次处理方式 |
|---|---|---|
| 直接服务或发布机构 | 腾讯、东方财富、新浪、Tushare、TickFlow、SEC | 记为实际请求的服务方；商业聚合服务更底层供应链未披露时保留未知 |
| Python/Go 库与协议客户端 | AKShare、efinance、yfinance、yahooquery、pytdx、mootdx | 追到具体函数与端点；不能每个库算一家独立上游 |
| 文件、缓存与框架 | CSV、SQLite、Parquet、Qlib 数据目录、local | 标明数据入口；文件本身不证明原始供应商、历史时点或授权 |
| 新闻搜索与模型 | Tavily、Exa、RSSHub、LLM API | 检索平台与原文发布方分开；模型通常负责分析，不提供证券行情 |

例外需要按用途判断：marketingdashboard 从 OpenRouter 获取模型价格和调用排行，因此 OpenRouter 在这个项目里确实是 **AI 行业指标的数据来源**，但不是 A 股行情来源。

## 对观势最有用的发现

后续落地建议见[数据源取舍与分钟验收方案](../../docs/development/source-selection-and-acceptance.md)：明确主源候选、核对源及分钟完整性、单位、历史、权限的检查步骤；该方案尚未执行新采样。

1. **已有公开上游没有缺席，缺的是策略所需口径和验收。** 观势之前已采过新浪、东财原始分钟和腾讯日线；本次新发现的包装方式，不会自动解决旧样本的完成时点、单位、缺口与跨源差异。历史结果见 [公开样本 PoC](../../docs/development/next03-public-poc.md)，不算作本次实采。
2. **“备源”需要按底层去重。** AKShare 的东财函数、efinance、东财直连不能算三家独立行情；yfinance、yahooquery、Yahoo chart 也是同一 Yahoo 上游的不同调用方式。TickFlow/Fuyao 等更底层来源未充分披露，不能仅凭产品名字断言彼此独立。
3. **实时价、分时曲线、分钟 OHLCV、长期分钟历史是四种能力。** MarketLens、PanWatch、stock-analysis-plugin 的所查 K 线入口以日频为主；marketingdashboard 的分时曲线也不自动构成标准完成分钟批次。Tushare 历史分钟与分钟 RT 的权限分开，见 [历史分钟官方说明](https://tushare.pro/document/2?doc_id=370)、[实时分钟官方说明](https://tushare.pro/document/2?doc_id=374)。
4. **与盘中接入更相关的参考入口**是 tick-stock-panel 的能力路由、Wyckoff 的 TickFlow 客户端、a-stock-data 的腾讯分钟、jcp 的通达信/新浪路径，以及 vnpy 的专业数据适配。这是后续源码研究优先级，不代表本轮建议购买或替换供应商。TdxQuant、普通通达信客户端、迅投 QMT/xtquant 是不同接入体系。
5. **新闻与基本面可以单独补齐。** 腾讯/东财/新浪负责行情，巨潮/交易所负责公告，财联社/新浪/东财/华尔街见闻提供资讯，Tushare/BaoStock/东财提供财务，是多项目实际采用的组合。新闻抓取成功不证明证券分钟输入合格。
6. **不能继承上游的静默兜底。** Kronos 的单个示例可能返回生成样本；TradingAgents-CN 有模拟新闻函数；AlphaSift 不同日线备源可能切换复权口径；部分项目缓存旧值。观势必须保留真实/模拟、陈旧、来源和复权标签，继续按自己的数据契约验收。
